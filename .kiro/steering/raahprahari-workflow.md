# RaahPrahari workflow

- Build on existing working code. Use pnpm for commands.
- Work one bounded task at a time; inspect only the relevant files.
- Never fake auth, AI, delivery, or review success. Show real or explicit unknown states.
- Preserve account-scoped drafts and explicit unknown states (unknown is never green).
- The backend enforces roles; UI checks are convenience only.
- Keep secrets out of output, logs, and files.
- No dependency changes, commit, push, or deploy without permission.
- Use focused checks while iterating. Run the repository completion checks from AGENTS.md before declaring a task complete.
